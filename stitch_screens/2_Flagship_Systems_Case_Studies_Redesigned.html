Vitamend

OCR-driven medical data extraction and processing pipeline.

Python Tesseract OCR AWS Lambda

The Problem

Manual entry of clinical trial data from unstructured PDF reports led to a 15% error rate and significant operational bottlenecks, delaying critical analysis phases.

Architecture & Solution

Developed a serverless ETL pipeline triggered by S3 uploads. Implemented a multi-stage OCR process using Tesseract, followed by a NLP layer for entity extraction and validation against medical ontologies.

  • check Event-driven AWS Lambda architecture for isolated processing.
  • check Custom heuristic engine for layout detection in highly variable PDFs.

Tradeoffs

Chose Tesseract over commercial APIs to control data residency, trading initial setup complexity for long-term security and cost predictability.

Vocalis

Real-time voice sentiment analysis engine.

C++ WebRTC TensorFlow

The Problem

Customer support agents lacked real-time feedback on caller emotional states, leading to suboptimal escalation routing and decreased satisfaction scores.

Architecture & Solution

Built a low-latency audio processing pipeline integrating with SIP trunks via WebRTC. Used quantized TensorFlow models optimized for CPU inference to analyze prosody and pitch variations on the edge.

Tradeoffs

Prioritized inference speed over deep linguistic analysis (NLP) in the critical path to ensure synchronous UI updates without audio lag.

OptraFi

High-throughput financial transaction reconciliation system.

Go Kafka PostgreSQL

The Problem

Legacy nightly batch processes for reconciling internal ledgers against partner bank APIs were failing under scale, causing delayed settlements.

Architecture & Solution

Transitioned to a streaming architecture using Apache Kafka and Go-based microservices for concurrent matching logic, utilizing partitioning strategies to maintain ordering guarantees.

Tradeoffs

Accepted eventual consistency for dashboard reporting in exchange for absolute strict consistency and high availability in the core reconciliation engine.

WelcomeToMyCity

Geospatial discovery platform for urban environments.

React Native GraphQL Redis

The Problem

Users experienced severe lag when querying highly dense geospatial point-of-interest data on mobile devices over unstable 4G connections.

Architecture & Solution

Implemented a GraphQL API over a Redis-backed geohash cache. Used client-side clustering algorithms and an optimistic UI strategy to pre-fetch data based on user movement vectors.

Tradeoffs

Sacrificed real-time inventory precision for aggressive caching to ensure a fluid map panning experience.
